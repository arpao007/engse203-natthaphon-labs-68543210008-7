# DATABASE_CHOICES

## 1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB

โปรเจกต์นี้เลือก SQLite เพราะข้อมูลมีโครงสร้างชัดเจน มีตาราง users และ requests ที่มีความสัมพันธ์กัน จึงเหมาะกับฐานข้อมูลเชิงสัมพันธ์และการใช้ SQL รวมถึงติดตั้งและใช้งานได้ง่ายสำหรับระบบขนาดเล็กถึงกลาง

## 2. ถ้าวันหนึ่งต้องเปลี่ยนไป MongoDB จะกระทบชั้นไหนบ้าง

หากเปลี่ยนไป MongoDB จะกระทบทั้ง service และ controller เพราะ MongoDB ทำงานแบบ asynchronous ต้องใช้ async/await ในการดึงข้อมูลและส่งผลลัพธ์กลับมา ทำให้ controller ต้องรองรับการทำงานแบบ async เพิ่มเติม

## 3. async จำเป็นเมื่อไร ไม่จำเป็นเมื่อไร

async จำเป็นเมื่อฐานข้อมูลหรือบริการทำงานผ่านเครือข่าย เช่น MongoDB Atlas หรือ Turso ที่ต้องรอการตอบกลับจากเซิร์ฟเวอร์ ส่วน SQLite ที่ทำงานอยู่ในเครื่องเดียวกันสามารถทำงานแบบ synchronous ได้ จึงไม่จำเป็นต้องใช้ async ในหลายกรณี
